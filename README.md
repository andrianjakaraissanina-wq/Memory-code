# Mini Network Tools

Projet Java débutant réalisé par RAISSA - L2 Réseaux - Antsiranana

## Description
Petit outil en ligne de commande pour comprendre les bases du réseau :
- Vérifier si une IP est locale ou publique
- Tester la connectivité avec un ping

## Technologies
- Java
- java.net.InetAddress

## Comment lancer
```bash
javac src/*.java
java -cp src Main
```
